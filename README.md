# 리그 오브 레전드 — 3D 미니 MOBA (League of Legends Mini MOBA)

React + three.js로 만든 **3D 탑다운 미니 MOBA 게임**입니다. 챔피언을 조종해 미니언 웨이브를 이끌고, 골드로 아이템을 사서 성장한 뒤 적 넥서스를 파괴하면 승리합니다.

🎮 **플레이:** https://leesuhwan0902-prog.github.io/league-of-legends/

## 게임 특징

- **3D 전장** — three.js 실시간 렌더링, 그림자·포그·강·정글 장식, 부드러운 추적 카메라
- **챔피언 조작** — 좌/우 클릭으로 이동, 마우스 커서 방향으로 스킬 발동
- **4개의 스킬 (Q/W/E/R)** — 마나 소모 + 재사용 대기시간, 주문력(AP) 계수 반영
- **💰 골드 시스템** — 미니언 **막타**, 타워, 챔피언 처치로 골드 획득 + 초당 패시브 골드
- **🛒 아이템 상점** — `B` 키로 상점을 열고 최대 6칸까지 구매. 공격력·주문력·체력·마나·이동속도·공격속도 강화
- **미니언 웨이브** — 13초마다 양 진영에서 스폰되어 레인을 따라 진격
- **타워 & 넥서스** — 사거리 내 적 자동 공격, 넥서스 파괴 시 승리
- **적 챔피언 AI** — 추격·스킬 사용·저체력 후퇴
- **레벨업 / XP** — 처치로 성장 (최대 18레벨)
- **미니맵 & HUD** — 체력/마나, 스킬 쿨다운, 골드, 인벤토리, 스코어보드

## 조작법

| 입력 | 동작 |
| --- | --- |
| 좌/우 클릭 | 해당 지점으로 이동 |
| `Q` | 비전 투척 — 직선 관통 투사체 (40 MP) |
| `W` | 충격파 — 주변 광역 피해 (50 MP) |
| `E` | 질풍 — 커서 방향 순간이동 (40 MP) |
| `R` | 대재앙 — 지정 지점 대형 광역 피해 (100 MP) |
| `B` | 상점 열기/닫기 |
| `Space` | 이동 정지 |

## 골드 & 아이템

| 획득처 | 골드 |
| --- | --- |
| 미니언 막타 (근접) | 26 |
| 미니언 막타 (원거리) | 20 |

아이템은 롱소드·단검·루비 수정·사파이어 수정·장화·주문서·곡괭이·거인의 허리띠·마법사의 고서·대천사의 지팡이·무한의 대검·수호 천사 등 12종이며, **최대 6칸**까지 소지할 수 있습니다.

## 승리 조건

적 진영의 **넥서스**를 파괴하면 `VICTORY`, 아군 넥서스가 파괴되면 `DEFEAT`입니다.

## 기술 스택

- **React 19** — HUD, 상점, 오버레이 UI
- **three.js** — 3D 전장 렌더링 (WebGL)
- **Canvas 2D** — 체력바·이름·이펙트·데미지 텍스트·미니맵 오버레이
- **Vite 8** — 개발 서버 / 번들링
- **oxlint** — 린트
- **gh-pages** — GitHub Pages 배포

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run lint     # 린트
npm run deploy   # 빌드 후 gh-pages 브랜치로 배포
```

## 프로젝트 구조

```
src/
├─ components/
│  ├─ GameCanvas.jsx   # 캔버스 2개(WebGL/2D) + 게임 루프 + 입력 처리
│  └─ Hud.jsx          # 체력/마나, 골드, 인벤토리, 스킬바, 상점, 오버레이
├─ game/
│  ├─ Game.js          # 시뮬레이션 · AI · 전투 · 골드/아이템 시스템
│  ├─ Scene3D.js       # three.js 씬/카메라/메시 동기화
│  ├─ overlay.js       # 2D 오버레이 (체력바·이펙트·미니맵)
│  ├─ constants.js     # 밸런스 수치, 맵/스킬/아이템 정의
│  └─ factory.js       # 유닛 생성 팩토리
├─ App.jsx
└─ index.css
```
